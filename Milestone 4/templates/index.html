Multi-Agent Resolution Architecture

SupportPilot runs specialized cooperative agents orchestrated with LLM routing, enterprise TF-IDF / vector knowledge retrieval, automatic diagnosis, and live Jira/Email tool calling.

1. Router Agent

Analyzes issue semantics, extracts category keywords, detects urgency and routes to appropriate resolver agent.

2. Retrieval Agent

Performs TF-IDF and cosine similarity search across enterprise standard operating procedures.

3. Diagnosis Agent

Synthesizes contextual knowledge into concrete, numbered verification steps with citations.

4. Escalation Agent

Evaluates escalation criteria; triggers Jira issue creation & SMTP email notifications.
